# warpin-utils

Utility packages: account, converter, excel, fileutil, oauthstate, sanitizer, stringutil.

Module path: `github.com/time-origin/warpin-go-common/warpin-utils`.
Release tags: `warpin-utils/vX.Y.Z`. The initial `v0.1.0` is not published yet.

For local development, run `go test ./...` here with the root workspace enabled.
For independent checks before publication, run from the repository root:

```bash
python3 scripts/check.py --module warpin-utils test ./...
```

See the root README for migration, dependency injection and release instructions.
