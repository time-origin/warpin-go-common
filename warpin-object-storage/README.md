# warpin-object-storage

Google Cloud Storage adapter under gcs, including upload and signed URLs.

Module path: `github.com/time-origin/warpin-go-common/warpin-object-storage`.
Release tags: `warpin-object-storage/vX.Y.Z`. The initial `v0.1.0` is not published yet.

For local development, run `go test ./...` here with the root workspace enabled.
For independent checks before publication, run from the repository root:

```bash
python3 scripts/check.py --module warpin-object-storage test ./...
```

See the root README for migration, dependency injection and release instructions.
