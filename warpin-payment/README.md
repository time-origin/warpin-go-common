# warpin-payment

Ysepay Xiao-Y cashier client under ysepay, including optional H5 routing.

Module path: `github.com/time-origin/warpin-go-common/warpin-payment`.
Release tags: `warpin-payment/vX.Y.Z`. The initial release version is `v0.1.0`.

For local development, run `go test ./...` here with the root workspace enabled.
For independent checks before publication, run from the repository root:

```bash
python3 scripts/check.py --module warpin-payment test ./...
```

See the root README for migration, dependency injection and release instructions.
