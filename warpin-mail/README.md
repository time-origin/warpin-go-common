# warpin-mail

SMTP, AWS SES, Aliyun DirectMail and embedded templates at the module root.

Module path: `github.com/time-origin/warpin-go-common/warpin-mail`.
Release tags: `warpin-mail/vX.Y.Z`. The initial release version is `v0.1.0`.

For local development, run `go test ./...` here with the root workspace enabled.
For independent checks before publication, run from the repository root:

```bash
python3 scripts/check.py --module warpin-mail test ./...
```

See the root README for migration, dependency injection and release instructions.
